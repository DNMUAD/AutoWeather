# AutoWeather

The program automatically sends the weather to WeChat using wxauto4



\#####项目目标

自动获取高德的实时天气信息和预报天气信息，以不同的语言风格模板生成天气提醒段落，通过wxauto4调用weixin发送消息给特定的用户。



\#####运行环境

1.Windows11

2.Python3.12.7

3.WeChat



\#####技术选型

1.python

2\.高德天气Api

3.wxauto4库



\#####开发工具

1.vscode

2.deepseek-v4.1-flash
